# 🎨 Meme Addition Guide

Quick guide to adding your own memes to the Pose Meme Matcher!

## 📁 Folder Structure

```
memes/
├── arms_crossed/     # Arms crossed over chest
├── thumbs_up/        # Thumbs up gesture
├── peace_sign/       # Peace/victory sign
├── facepalm/         # Hand covering face
├── thinking/         # Hand on chin
├── shrug/            # Shoulder shrug
├── salute/           # Military salute
└── default/          # Shown when no gesture detected
```

## ✅ How to Add Memes

1. **Find your meme** (download or create it)
2. **Choose the right gesture folder** based on when you want it to appear
3. **Drop the image file** into that folder
4. **Done!** The app will automatically detect it

### Supported Formats
- PNG (.png)
- JPEG (.jpg, .jpeg)
- GIF (.gif)
- BMP (.bmp)
- WebP (.webp)

## 🎯 Gesture Detection Guide

### thumbs_up
- Raise your hand with thumb pointing up
- Hand should be at or above shoulder level
- Works with either hand

### peace_sign
- Make a peace/victory sign near your face
- Hand should be close to your face
- Works with either hand

### facepalm
- Cover your face with your palm
- Hand should be very close to face
- Classic facepalm position

### thinking
- Place hand on or near your chin
- The classic "thinking pose"
- Works with either hand

### arms_crossed
- Cross your arms over your chest
- Both hands should be visible
- Can be loose or tight crossing

### shrug
- Raise both hands out to sides, palms up
- Classic "I don't know" gesture
- Both hands should be raised

### salute
- Raise hand to forehead/temple area
- Military salute position
- Works with either hand

### default
- Shown when no specific gesture is detected
- Good for "waiting" or "neutral" memes
- Add funny "strike a pose" type images here

## 💡 Tips for Best Results

1. **Use clear, high-quality images** - they'll look better on screen
2. **Mix it up** - add multiple memes per gesture for variety
3. **Test your gestures** - some poses work better than others
4. **Keep it fun** - this is a hobby project, add memes you'll enjoy!
5. **Hot reload** - Click "Reload Memes" button to refresh without restarting

## 🔥 Pro Tips

- **Add 3-5 memes per gesture** for good variety
- **Portrait/square images** work best for the display
- **Avoid huge files** - resize images to ~1000px for faster loading
- **Reaction memes** work great (surprised face, approval, disapproval, etc.)
- **Match the emotion** - facepalm memes for disappointment, thumbs up for approval, etc.

## 🚀 Quick Start Collection

If you're just getting started, here's a suggested minimum:
- 3-5 default memes (for when no gesture is detected)
- 2-3 thumbs up memes (approval/success)
- 2-3 facepalm memes (disappointment/cringe)
- 2-3 thinking memes (contemplation)

Then expand from there as you test and see what gestures you use most!

## 🐛 Troubleshooting

**Meme not showing up?**
- Check file extension is supported (.png, .jpg, etc.)
- Click "Reload Memes" button
- Check terminal output for loading errors

**Wrong meme appearing?**
- Make sure image is in the correct gesture folder
- Adjust your pose - try making it more exaggerated
- Check the gesture detection guide above

**App running slow?**
- Resize large images to ~1000px max
- Limit to reasonable number of memes (20-50 total is plenty)
